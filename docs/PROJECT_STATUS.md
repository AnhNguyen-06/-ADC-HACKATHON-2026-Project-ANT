# Project Status — Project ANT (Adaptive Navigation Technology)

**Current Milestone**: M0 (Governance & Foundation)  
**Status**: IN_PROGRESS  
**Target Completion Date**: 2026-09-13

## Executive Status
Project ANT is an accessibility-first indoor navigation assistant designed to empower blind and visually impaired employees to independently navigate structured office environments without reliance on sight or constant sighted assistance.

Development is structured into 9 strict milestones (M0 through M8). We are actively executing **Milestone M0**, establishing technical governance, state machines, architecture specifications, and task decompositions.

## Milestone Progress

- **M0: Foundation & Governance** — IN_PROGRESS (Rules written, state system deployed, docs created, test runner scaffolding in progress).
- **M1: Navigation Core** — PLANNED (Office graph model & Dijkstra algorithm).
- **M2: AprilTag Localization** — PLANNED (Passive landmark visual detection & state updates).
- **M3: Audio & Voice System** — PLANNED (Speech recognition & concise TTS feedback).
- **M4: Obstacle Detection** — PLANNED (Qualitative obstacle proximity classification).
